How to

1. Log in to your account. 2. Add the people you want to track in Contacts. 3. Click Run Summarizer to check recent emails from those people. 4. New summaries will appear in Summaries on the left side of the dashboard. 5. Click any summary to read the main points, action items, deadlines, and attachments. 6. Use AI Assistant if you want to ask questions in plain English. 7. Use Combined Report if you want one overview from several summaries. 8. Use Refine Summary if you want the summaries written in a style that fits you better.
